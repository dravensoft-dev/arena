# Spacing, radius, border, shadow, motion, layer, breakpoint, density and type scale values

What are the values behind `--sp-4`, `--r-md`, `--dur-mid`, `--z-modal` and `--dz-ctl-h`? Read this when markup of yours needs a length, a time, a stacking order, a control size or a type size. Your package's `arena.tokens.json` carries the same table.

## What are the groups?

**`--sp-*`** is the spacing scale. **`--r-*`** is the corner radius, and `--r-pill` is the fully rounded end. **`--bw`** and **`--bw-*`** are border widths. **`--shadow-*`** is the depth a surface casts.

**`--dur-*`** is how long a transition runs, and **`--ease-*`** is the curve it follows. **`--loop-*`** is the period of an animation that repeats. **`--z-*`** is the stacking order of the layers Arena draws, so a layer of yours sits above or below them by reading the same scale. **`--bp-*`** is the breakpoint widths.

**`--dz-*`** is the control and row sizes that `.arena-compact` and `.arena-comfortable` re-answer, and the density table below gives each class's value. **`--font-*`**, **`--fw-*`**, **`--fs-*`**, **`--lh-*`** and **`--ls-*`** are the type scale, and the type table below gives each one with the Tailwind utility that reads it.

## How do I use a value?

Read a value through its custom property, as `var(--sp-4)`, and never type the number. A later release may change a scale value, and a style plugin answers a role in its own way. A custom property follows either where a typed length does not.

A media query takes no `var()`. A frame that has to change at a breakpoint uses the `md:` variants or the viewport helper, as [`page.md`](./page.md) says.

## Where is the file?

`arena.tokens.json` sits at the root of the package. The file nests these values under `tokens`, beside `roles`. A key drops the leading `--`, so `sp-4` there is `--sp-4` here.
