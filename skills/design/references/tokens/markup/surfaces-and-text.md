# What do I paint a surface and its text with?

Read this when your own markup draws a page, a panel, a field, a line of text or the wash over a media frame, and you need the role.

**The colour roles below are what a page of yours reaches for**; the kernel has more, each for a surface Arena draws. Each role's full description is one entry in [`contracts/design/roles.json`](../../../../../contracts/design/roles.json).

| what you are drawing | the role |
|---|---|
| the page itself | `--fill-page` |
| a surface belonging to the page: a panel, a tile, a block of yours that reads as a card | `--fill-surface` |
| a surface floating over it: a popover, a layer of your own | `--fill-surface-floating` |
| a region recessed into a surface: a code block, a well | `--fill-surface-sunken` |
| a box somebody types into | `--fill-field` |
| the ground a value runs along, or the box a set of segments sits in | `--fill-track` |
| a heading | `--ink-heading` |
| text somebody reads, and the default answer for any text slot | `--ink-body` |
| the small line above a title that says what kind of thing this is | `--ink-eyebrow` |
| text held back: a caption, a hint, a timestamp | `--ink-muted` |
| a figure a reader compares: a price, a total, a column of numbers of yours | `--ink-figure` |
| an action set as text rather than drawn as a button: an undo, a retry | `--ink-action` |
| a key a reader presses, spelled in a cap or at a row's edge | `--ink-key` |
| a link in running text, underlined however it is coloured | `--ink-link` |
| the wash a media frame draws under anything laid over it | `--overlay-media` |

**A role says which colour the text takes, and a level says how far it is held back**, and text
needs both. Under the default style plugin `--ink-muted` and `--ink-body` resolve to the same
colour. What makes the held-back register held back is the level mixed into it. So a bare
`var(--ink-muted)` paints a caption at the strength of body copy, and nothing reports it.
Spend one the way every Arena component spends it:

```css
color: color-mix(in oklab, var(--ink-muted) var(--level-ink-muted), transparent);
```

`--level-ink-body`, `--level-ink-quiet` and `--level-ink-muted` are the held-back ones, the quiet one for a label that sits between body copy and a caption. `--level-ink-full` holds a figure or a text action at full strength. All of them are in
[`contracts/design/colors.css`](../../../../../contracts/design/colors.css). Each is a floor rather than a
constant. `arena build` raises one for a palette whose ink has too little room to clear its
contrast bar. So a percentage of your own is the one value on this page that cannot follow the
palette it was written against.

| role | what it is |
| --- | --- |
| `--fill-field` | The fill of a box the user types into: an input, a textarea, a select, the confirmation field a destructive dialog asks for |
| `--fill-page` | The fill of the page itself, the floor everything else stands on |
| `--fill-surface` | The fill of a surface that belongs to the page: a card, a stat card, a table's frame, an empty state |
| `--fill-surface-floating` | The fill of a surface that floats over the page: a menu, a dialog, a toast, a sheet, a command palette, a bulk action bar |
| `--fill-surface-raised` | The fill of a small readout raised over the content it annotates: a chart's tooltip over the plot |
| `--fill-surface-sunken` | The fill of a region that reads as recessed INTO a surface: a code block inside a card, a preview well, the track a value sits in |
| `--fill-track` | The ground a value runs along or a set of segments sits in, drawn as a strip across a surface rather than as a region something is placed inside: a progress bar's track, a segmented control's track, the head row of a table |
| `--ink-action` | The colour of an action set as text rather than drawn as a control: a toast's undo or retry |
| `--ink-body` | The colour of text somebody reads |
| `--ink-eyebrow` | The colour of an eyebrow |
| `--ink-figure` | The colour of a figure or a code a reader compares or scans for: a numeric cell of a table and the value beside it in the stacked card a narrow table becomes, the count of a bulk action bar, the target an activity feed's row acted on |
| `--ink-heading` | The colour of a heading |
| `--ink-key` | The colour of a key: an ArenaKbd cap, the escape cap and a trailing shortcut |
| `--ink-link` | The colour of a link set in running text: an ArenaLink in a sentence, a help line, a card body |
| `--ink-muted` | The colour of text held back: a caption, a hint, a timestamp, a secondary line |
| `--overlay-media` | The wash a media frame draws under anything laid over it, so a caption or a mark stays readable against an image nobody chose |
