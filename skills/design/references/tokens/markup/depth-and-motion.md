# What do I give my own markup depth and motion with?

Read this when your own markup casts a shadow, lifts under the pointer or runs a transition.

A shadow role names the depth a surface casts, and a motion role names how long a change runs and the curve it follows. The steps are on [the motion page](../scales/motion-and-layers.md).

**Depth and motion are composed from a shadow and a transition.** A resting surface takes a `--shadow-*-rest` role and a lifted one takes `--shadow-control-raised`, `--shadow-surface-floating` or `--shadow-surface-deep`. A response to the pointer takes `--dur-hover` with `--ease-hover`, a change the reader follows takes `--dur-state` with `--ease-state`, and a pressable control adds `--press-scale` and `--lift-control`.

**An entrance reads the deep pair or the floating pair.** A surface of yours that commands the screen arrives on `--dur-enter-deep` with `--ease-enter-deep`, and one floating over the page arrives on `--dur-enter-floating` with `--ease-enter-floating`. ArenaDialog reads the deep pair, and ArenaMenu and ArenaTooltip read the floating pair.

**Reduced motion is one rule.** Under `prefers-reduced-motion: reduce`, an entrance keeps its fade and drops its travel, and a repeating animation slows to `--loop-reduced`.

Your markup and Arena's components both read the roles on this page. A role keeps its name until a major release, and its value is the style plugin's to change in any release.

| role | question | utility | combines with |
| --- | --- | --- | --- |
| `--dur-enter-deep` | How long does a dialog, sheet or other surface that commands the screen take to arrive? | none | none |
| `--dur-enter-floating` | How long does a menu, tooltip or other surface floating over the page take to arrive? | none | none |
| `--dur-hover` | How long does a hover or press response take? | none | none |
| `--dur-state` | How long does a state change the user follows, such as a switch moving, take? | none | none |
| `--ease-enter-deep` | What easing curve does a surface that commands the screen follow as it arrives? | none | none |
| `--ease-enter-floating` | What easing curve does a surface floating over the page follow as it arrives? | none | none |
| `--ease-hover` | What easing curve does a hover or press response follow? | `ease-hover` | none |
| `--ease-state` | What easing curve does a state change the user watches, such as a switch moving, use? | `ease-state` | none |
| `--lift-control` | How far does a control rise under the pointer? | none | none |
| `--press-scale` | What scale does a control shrink to while it is held down? | none | none |
| `--shadow-control-raised` | What shadow does a control rise to under the pointer? | `shadow-control-raised` | none |
| `--shadow-control-rest` | What shadow does a button carry at rest? | `shadow-control-rest` | none |
| `--shadow-surface-deep` | What shadow does a dialog, sheet or sign-in card carry as it commands the screen? | `shadow-surface-deep` | none |
| `--shadow-surface-floating` | What shadow does a menu, toast or tooltip floating over the page carry at rest? | `shadow-surface-floating` | none |
| `--shadow-surface-rest` | What shadow does a card or panel carry at rest on the page? | `shadow-surface-rest` | none |
