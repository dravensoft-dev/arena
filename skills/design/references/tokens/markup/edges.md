# What do I draw a line, a corner and a border with?

Read this when your own markup draws the line around a surface, a control or a field, the rule between two things, or a corner.

| what you are drawing | the role |
|---|---|
| the line enclosing a surface, and the default ground line | `--edge-surface` |
| the line around a floating surface | `--edge-surface-floating` |
| the line around a control, a quiet control, a field, a marker | `--edge-control`, `--edge-control-quiet`, `--edge-field`, `--edge-marker` |
| the rule dividing one thing from the next inside a surface | `--edge-separator` |

Each edge role has a width beside it: `--bw-surface`, `--bw-control`, `--bw-field`,
`--bw-separator` and `--bw-marker`. So a border of yours takes two roles, never a length you chose.

| role | what it is |
| --- | --- |
| `--bw-control` | The border of a pressable control |
| `--bw-field` | The border of a typable field |
| `--bw-marker` | The border of a marker, paired with r-marker for the same family and the same reason |
| `--bw-separator` | The line that divides one thing from the next INSIDE a surface: a table row from the row under it, a sheet's head from its body, a tab strip from its panel |
| `--bw-surface` | The border that encloses a surface, and therefore Arena's default grouping signal |
| `--edge-axis` | Which colour the axis lines, the zero line and the crosshair of a chart are drawn in, read by the line, bar, horizontal bar, scatter, radar and pyramid charts, by the crosshair of an interactive sparkline and by the band-edge ticks of a gauge, and not by the doughnut, which has no axis |
| `--edge-control` | The colour of the line around a control the user presses |
| `--edge-control-quiet` | The colour of the line around a control that is present but not offering itself: a ghost icon button, an unselected page in a pager, the track behind a segmented control, a calendar's nav arrows |
| `--edge-field` | The colour of the line around a typable field |
| `--edge-marker` | The colour of the ring around a MARKER: an avatar, a delta badge |
| `--edge-separator` | The colour of the rule that divides one thing from the next inside a surface |
| `--edge-surface` | The colour of the line that encloses a surface |
| `--edge-surface-floating` | The colour of the line around a surface that floats over the page |
| `--r-control` | The corner of a CONTROL the user presses: a button, an icon button, a menu item, a pagination page, a navigation row |
| `--r-control-sm` | The corner of a control too small to carry the full control radius: a checkbox box, a segment of a segmented control |
| `--r-field` | The corner of a FIELD the user types into: an input, a select, a textarea |
| `--r-marker` | The corner of a MARKER: a tag, a delta badge, a keyboard cap, an inline code chip |
| `--r-media` | The corner of a MEDIA frame: the box an image, a video or a stand-in glyph is clipped to |
| `--r-surface` | The corner of a SURFACE that belongs to the page: a card, a panel, a dialog, a sheet, a table frame |
| `--r-surface-floating` | The corner of a surface that floats over the page: a menu, a toast, an alert, a bulk action bar |
