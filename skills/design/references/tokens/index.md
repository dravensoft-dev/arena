# Which token page do I read?

Read this when you need a role or a scale value and do not yet know which page holds it. Who you are decides the branch.

Your own markup reads roles and scales, and a style plugin answers roles. A value lookup needs neither.

- **You write markup of your own**, and you need the custom property for a fill, a line, a space, a type, a shadow or a layer.
- **You write a style plugin**, and you answer the roles of the kernel by task.
- **Your plugin answers a family option**, such as a size or an emphasis of one component.
- **You need a value**, such as `--sp-4` or `--dur-mid`, and no role.

`arena.tokens.json` sits at the root of the package. The file nests these values under `tokens`, beside `roles`. A key drops the leading `--`, so `sp-4` there is `--sp-4` here.
