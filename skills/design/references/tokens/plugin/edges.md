# Which roles answer a corner and a line?

Read this when your style plugin answers a corner radius, a border width or the colour of a line.

**The steps live in [`effects.json`](../../../../../contracts/design/effects.json)** for these:

| Roles | Scale |
|---|---|
| `r-*` | `r` |
| `bw-*` | `bw` and `bw-strong`, a pair rather than a ladder, so the alias carries no step |

An `edge-*` role is a colour role, so an answer is a palette colour as a `{color.*}` alias.

A plugin answers each `r-*` role with an alias of a step of the `r` scale. Each `bw-*` role takes an alias of the `bw` pair, and each `edge-*` role a colour.

An answer of `0` for `--bw-control` erases the border of a button, the box of a checkbox and the ring of a radio.
