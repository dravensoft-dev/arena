# Which roles answer a face, a weight, a size and a tracking?

Read this when your style plugin answers a font family, a weight, a leading, a tracking, a text transform or a size.

**In [`typography.json`](../../../../../contracts/design/typography.json)** for these:

| Roles | Scale |
|---|---|
| `fw-*` | `fw` |
| `ff-*` | `font`, which resolves to the families your config declares |
| `track-*` | `ls` |
| `lh-*` | `lh` |
| `step-title-*` | `fs` |

**In [`spacing.json`](../../../../../contracts/design/spacing.json)** for these:

| Roles | Scale |
|---|---|
| `step-eyebrow`, `step-label` | `dz` |

**`measure-prose` reads no scale at all**, and a literal is the only answer for it.

**A unit the type does not carry**, through `$extensions`. Five roles need it and the rest do
not: `track-heading`, `track-eyebrow`, `track-label` and `track-trail` take `em`, and `measure-prose` takes
`ch`. Only a literal needs it, because every `ls.*` step carries `em` already and an alias of one emits
`em` with no `$extensions`. A tracking role answered with a bare number and no unit emits that
number, which is not a valid letter spacing, and the declaration is dropped, so the text keeps the spacing it inherits, normally `normal`.

```json
"measure-prose": { "$type": "number", "$value": 86,
  "$extensions": { "com.dravensoft.arena": { "cssUnit": "ch" } } }
```

A plugin answers each `ff-*`, `fw-*`, `track-*`, `lh-*` and `step-*` role with an alias of the scale of the same axis, and `measure-prose` and each `tt-*` role with a literal.

Your markup and Arena's components both read the roles on this page. A role keeps its name until a major release, and its value is the style plugin's to change in any release.

| role | question | type | user scale | default |
| --- | --- | --- | --- | --- |
| `--ff-eyebrow` | Which font family does an eyebrow line above a title use? | fontFamily | none | none |
| `--ff-heading` | Which font family does a heading use? | fontFamily | none | none |
| `--ff-label` | Which font family do field labels, column headers and badges use? | fontFamily | none | none |
| `--fw-control` | How heavy is the label text on a button, tab or menu item? | fontWeight | none | none |
| `--fw-eyebrow` | How heavy is the type of an eyebrow line above a title? | fontWeight | none | none |
| `--fw-heading` | How heavy is the type of a heading in the display face? | fontWeight | none | none |
| `--lh-heading` | How much leading does a heading have? | number | none | none |
| `--lh-prose` | How much leading does body text people read have? | number | none | none |
