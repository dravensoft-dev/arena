# ArenaFilterBar by hand (Angular)

Serve the tree with `bun run demos`, open `/frameworks/angular/components/navigation/arena-filter-bar/ArenaFilterBar.demo.generated.html`, and check in a real browser:

- The row wraps, and takes one column at phone width, with a real select, input and segmented control projected.
- The baselines of the controls align when one lacks a label.
- After removing a chip from the keyboard, focus is on the next chip.
- A screen reader announces the group's name and the list's name.
