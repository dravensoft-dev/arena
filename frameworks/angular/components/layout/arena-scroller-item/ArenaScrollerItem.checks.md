# ArenaScrollerItem by hand (Angular)

Serve the tree with `bun run demos`, open `/frameworks/angular/components/layout/arena-scroller-item/ArenaScrollerItem.demo.generated.html`, and check in a real browser:

- The cell is exactly as wide as the row's `arena-scroller-item` width, whatever it contains.
- Every cell is the same width and the same height, whatever component sits inside it.
