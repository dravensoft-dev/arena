# ArenaPinInput by hand (Angular)

Serve the tree with `bun run demos`, open `/frameworks/angular/components/forms/arena-pin-input/ArenaPinInput.demo.generated.html`, and check in a real browser.

A text message autofill on iOS and on Android fills every cell. The number pad shows for `numeric`. Tab crosses the whole group in one press. Only the focused cell carries the focus ring. Six cells fit a 390px screen.
