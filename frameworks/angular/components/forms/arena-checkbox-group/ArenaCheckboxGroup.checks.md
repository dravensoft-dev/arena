# ArenaCheckboxGroup by hand (Angular)

Serve the tree with `bun run demos`, open `/frameworks/angular/components/forms/arena-checkbox-group/ArenaCheckboxGroup.demo.generated.html`, and check in a real browser.

Tab visits each box once and Space toggles it. A native form submits every ticked value under the one `name`. A screen reader announces the group by its name on entering it.
