# ArenaCombobox by hand (Angular)

Serve the tree with `bun run demos`, open `/frameworks/angular/components/forms/arena-combobox/ArenaCombobox.demo.generated.html`, and check in a real browser.

Check that the list escapes an `overflow: hidden` card. The list flips above the field near the bottom of the screen and is as wide as the field. The cursor row scrolls into view. A screen reader announces the count after typing. On a phone, the soft keyboard leaves the list in view.
