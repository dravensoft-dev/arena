# ArenaNumberField by hand (Angular)

Serve the tree with `bun run demos`, open `/frameworks/angular/components/forms/arena-number-field/ArenaNumberField.demo.generated.html`, and check in a real browser.

A phone's decimal keypad, where iOS has no minus key and the steppers reach a negative number. The stepper target under `arena-comfortable`. Home and End against a bound. The focus ring on the field.
