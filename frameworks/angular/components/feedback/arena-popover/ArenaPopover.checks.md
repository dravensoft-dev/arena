# ArenaPopover by hand (Angular)

Serve the tree with `bun run demos`, open `/frameworks/angular/components/feedback/arena-popover/ArenaPopover.demo.generated.html`, and check in a real browser.

A suite has no layout, so a person checks two things. Scroll the page with the panel open and see the panel follow its trigger. Open one from inside a dialog and see the panel above the dialog.
