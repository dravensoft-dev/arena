# ArenaBadge by hand (Angular)

Serve the tree with `bun run demos`, open `/frameworks/angular/components/display/arena-badge/ArenaBadge.demo.generated.html`, and check in a real browser:

- Each of the five tones reads as its own colour against `--surface-card`.
- The mono uppercase treatment survives at the smallest text size.
- With `dot`, the dot takes the tone's own ink (`bg-current`) rather than a second colour.
