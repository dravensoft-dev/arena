# ArenaPinInput by hand (React)

Serve the tree with `bun run demos`, open `/frameworks/react/components/forms/arena-pin-input/ArenaPinInput.demo.generated.html`, and check in a real browser.

The text message autofill on iOS and Android lands the whole code. The number pad appears for `numeric`. Tab leaves the group in one press. The focus ring sits on one cell only. Six cells fit at 390px.
