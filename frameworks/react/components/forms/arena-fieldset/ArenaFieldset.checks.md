# ArenaFieldset by hand (React)

Serve the tree with `bun run demos`, open `/frameworks/react/components/forms/arena-fieldset/ArenaFieldset.demo.generated.html`, and check in a real browser.

In a browser, a disabled fieldset disables the checkboxes inside it. The legend sits above the fields at 390px, and a long legend wraps. A field disabled on its own inside a disabled set dims twice, and that reads as acceptable.
