# ArenaNumberField by hand (React)

Serve the tree with `bun run demos`, open `/frameworks/react/components/forms/arena-number-field/ArenaNumberField.demo.generated.html`, and check in a real browser.

A phone's decimal keypad, where iOS draws no minus, so a negative number comes from the steppers. The stepper target at `arena-comfortable`. Home and End against a bound. The focus ring on the field.
