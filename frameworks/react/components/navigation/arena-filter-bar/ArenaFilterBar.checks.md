# ArenaFilterBar by hand (React)

Serve the tree with `bun run demos`, open `/frameworks/react/components/navigation/arena-filter-bar/ArenaFilterBar.demo.generated.html`, and check in a real browser.

The wrap and the one-column shape at phone width, with a real select, input and segmented control inside. The controls' baselines line up when one has no label. After a keyboard removal, focus lands on the next chip. A screen reader announces the group name and the list name.
